## Live Hosting (fastest free options)

### 1. Netlify Drop (30 seconds)
1. Download the project zip.
2. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
3. Drag the `luna-sol-supernovas` folder onto the page.
4. You get an instant free public URL.

### 2. GitHub Pages
1. Add the two image files to an `assets/` folder in this repo:
   - `assets/logo.jpg`
   - `assets/hero-bg.jpg`
2. Repo Settings → Pages → Source = Deploy from a branch → Branch = `main` → Folder = `/ (root)`.
3. After 1–2 minutes the site will be live at:
   **https://cyb3rathl3t3.github.io/luna-sol-supernovas/**

### Local viewing
Open `index.html` in any modern browser. Keep the `assets/` folder next to it so the logo and background load.
